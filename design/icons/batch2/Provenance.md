# Asset provenance

All new geometry was authored directly as SVG paths for PrismQDA, using the supplied icon inventory and existing PrismQDA family as the reference. No third-party icon pack was imported or traced for this batch.

First-party reuse is intentional: page, note, tag, information and related scaffolds continue the earlier set. `set-about.svg` exactly reuses the Batch 1 information drawing. The two branded file icons embed flattened geometry from `brand-mark-small.svg` in the supplied Batch 1 package, which already incorporated the user's preferred luminous prism.

The package includes no font files. Preview text is rasterized or uses browser/system fonts; every letter or digit inside an SVG glyph is a path. The original Markdown inventory is included unchanged for traceability.
