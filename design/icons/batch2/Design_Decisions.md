# Batch 2 design decisions

| ID | Source issue | Implementation | Status |
| --- | --- | --- | --- |
| B2-01 | Existing family must continue | Reuse the established folded page, note and tag structures; do not replace Batch 1 | Continuity decision |
| B2-02 | Full-color brand files versus global outline rule | Only file-project and file-package receive approved spectrum facets; local gradients are retained | Brand-family exception |
| B2-03 | Source-family common sheet versus row-specific silhouettes | Use the sheet for documents and row-specific silhouettes for people, email, web, references and sets | Continuation of the foundation interpretation |
| B2-04 | Appearance explicitly half-filled | Fill one half with currentColor; keep all other non-brand glyphs unfilled | Row-specific exception, review pending |
| B2-05 | Fixed radius on tiny internal boxes | Use radius 2 on standard frames; cap radius where dimensions require it | Optical refinement, review pending |
| B2-06 | Selection region handles | Small square handles identify draggable control points | Row-specific drawing detail |
| B2-07 | Number column / numbered report outline | Render 1–2 and 1–3 as paths, never live text | Literal inventory metaphor |
| B2-08 | Repeated information symbol | set-about.svg exactly reuses Batch 1 st-info.svg paths under its required name | Intentional first-party geometry reuse |
| B2-09 | Correlate versus regression | Correlate has associated points without a fitted line; Regression adds a fitted line | Distinguish adjacent statistical actions |
| B2-10 | Summary grid versus framework matrix | Summary grid uses cell text marks; framework emphasizes only the first column | Distinguish synthesis tools from code matrices |
| B2-11 | Merge code versus merge work | Code merge has an arrowhead; team merge uses unheaded converging lines | Distinguish the actions while retaining the same family |
| B2-12 | Skip forward/back named separately despite directional-reuse rule | Supply both requested files with flattened mirrored path geometry, no transform attributes | Exact inventory coverage |
| B2-13 | AI-origin and security implications | Draw the requested symbols without badges implying automatic approval or certification | Semantic safeguard |
| B2-14 | Dense research metaphors at 16 px | Preserve requested semantics and show actual-size tests; require a visible UI label for complex tools | Further user review needed |

The main PrismQDA logo is not redesigned in this pack. Project and package badges reuse the compact mark from the approved logo package, preserving its facets and curved inner seam. The file containers are new drawings.
