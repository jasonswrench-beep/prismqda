Each card displays a large inspection view alongside 16, 20, and 24 CSS-pixel renders. Browser zoom changes their physical size. Interface glyphs inherit one color; the two branded file glyphs retain the approved prism spectrum. High contrast is a preview, not a conformance certification.

Using this pack

Extract the ZIP and open START_HERE.html. This gallery is self-contained and uses no remote assets. The actual SVG files are in ../../assets/icons/regular/ and brand/. Each inspection dialog can also save the displayed SVG.

Scope and continuity

There are 122 canonical SVGs: 120 themeable interface glyphs and two full-color brand-file icons. The full inventory now has 230 drafted canonical SVGs across Batches 1 and 2, including the 12 active workspace variants from Batch 1. Fourteen named Batch 3 icons remain. Counts describe drafted assets, not approved designs.

Preserved style

Regular glyphs use a 24 × 24 viewBox, 1.75-unit rounded strokes, and currentColor. Page, memo, tag, information, and control metaphors extend the existing family. The main PrismQDA logo is unchanged. It appears as a compact corner badge on Project file and Exchange package.

Declared exceptions

Appearance uses the half-filled circle requested in its inventory row. Only that interface glyph uses a currentColor fill. The two brand-file assets contain local gradient definitions and colored vector facets. Small inner frames cap their radius to fit. Region-control handles use deliberately square corners. Digits in Quantitize and Report outline are outlined paths, not text or fonts. These treatments are documented in the design-decision log.

Review and persistence

Select an icon to inspect its SVG, record Ready or Revise, and leave a note. Browser storage is best-effort for local files. Use Export review JSON to keep a portable copy. A Ready choice records your review preference; it does not automatically update the packaged registry or establish application accessibility.

Application integration

Inline an SVG or use a component that passes CSS color to it. An external <img> does not inherit the parent page’s currentColor in the same way. Provide the accessible action name on the actual button, and hide decorative SVGs from assistive technology. Brand gradient IDs need per-instance prefixes when repeated inline; this gallery applies them automatically.

Validation

The pack includes a standalone structural validator and a report of exact filename coverage, SVG structure, active-content exclusion, and rendered padding checks. Actual application testing with assistive technology and users remains outstanding. No design is marked user-approved by this pack.
