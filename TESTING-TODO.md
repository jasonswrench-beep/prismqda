# What only a person can check

Everything a program can test is tested by the test suite and the headless browser check. This list is what is left, with what to look for. Nothing here has been done yet. Tick a line and add the date when it has.

## Before beta 2: your own tests (development list of 2026-11-15, item 1)

The five tests only a person can run, in the order that is cheapest first. Each one points to the entry below that says what to do and what to look for; tick it there when it is done and add the date. None of them has been done by a person yet (scripts have driven the installer, the window and a second program's own code, which is not the same thing).

## Mixed Methods (alpha 38), to try with real material

The check used eight invented respondents (one survey document, a unit for each) and codes made for it; every number was worked out by hand.

- [ ] **Whether a case has a code, with your own coding.** Pick a code you have used a lot, make the variable, and compare it with what you know: does every case that should have the code say Yes? Open one case's documents and count the excerpts by eye against *How many excerpts carry a code*.
- [ ] **Cases whose text is split over several documents.** A case with three interviews: is *has a code* true when only one of them carries it (it should be)? Is the count the sum of the three?
- [ ] **Which of several codes a case has most.** Choose three or four codes that you think of as alternatives (for example a stance). Do the cases that tie read the way you would want? Would you rather break ties by something else (for instance the first code in your list)?
- [ ] **Variables into codes in a project that codes whole units.** Make codes from a variable of an interview project: is a case's text coded the way you would expect when a case has some speakers' turns set aside?
- [ ] **Taking it back.** After making codes from a variable, press *Take back what was just made*: are the codings gone and the codes retired in the Codebook? Would you rather the retired codes were removed from the Codebook altogether (there is no way to delete a code yet)?
- [ ] **The real window.** All of the above in the desktop window; the check used a browser only.
- [ ] **Joint displays on your own coding (alpha 39).** In the case-ordered display, order your cases by a number you care about (an age, a score) and read down the quotations: is it the table you would draw on paper? Do the quotations cut at a length that is enough to read? Is five the right most?
- [ ] **The typology table on real groups.** Choose three codes that name types of experience and two or three variables. Check a few figures by hand (a group's mean and the number of cases). Is it clear that a case can be in more than one group? Would you rather have exclusive groups (the code each case has most)?
- [ ] **The rest of the joint displays on your own coding (alpha 40).** Side-by-side: do the topics you would choose read well as rows, with a quotation and the numbers of the cases that have it? Deviation table: is "most and least typical of a group" the question you ask of your groups, and is the warning that z is a guide and not a test clear? Similarity: are the cases it calls most alike the ones you would pair by hand? Bubble plot: is size by excerpts and colour by mean weight what you want to see, and are the five steps of blue easy to tell apart?
- [ ] **The design, the matrix, and the log on a real study (alpha 40).** Choose the design that is yours and read what the template would make before you press it. Write three topics in the matrix with their marks, then change the coding and look again: do the words and numbers beside each follow it? Is the integration log the record a reviewer or a methods section would want, and are the five ways of bringing the data together the words you use? Make the report with the Mixed methods section and read it as a reader would.
- [ ] **A project saved at format 10.** It cannot be opened by an earlier version. Open an older project (format 9 or earlier) and check that it is brought forward with an untouched copy kept beside it.
- [ ] **A very wide table.** A typology table with a variable of ten categories and several codes is wide: does the box that scrolls sideways work with the keyboard and a screen reader?
- [ ] **A screen reader.** Only when you choose (see the note on NVDA): the two cards, the three options, the plan, and the result sentences should be spoken in a sensible order.
